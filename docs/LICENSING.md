# Cakupan lisensi

| Komponen                                                                           | Ketentuan                                                                                                                                             | Berkas                                                                         |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Kode sumber aplikasi (TypeScript/React, pembungkus Electron, skrip build/uji)      | Lisensi MIT                                                                                                                                           | `src/`, `desktop/`, `tools/`, `tests/`, `e2e/`, konfigurasi; teks di `LICENSE` |
| Kasus, soal, kunci jawaban, materi pembelajaran, dan data hasil ekstraksi workbook | **Tidak otomatis MIT.** Hak dan ketentuannya belum ditetapkan terpisah oleh pemilik; asal dan keterlibatan AI dijelaskan di `docs/CONTENT_SOURCES.md` | `data/`, `src/data/`, `src/learning/`                                          |
| Logo, lambang, dan ikon DEKRi Lab                                                  | **Tidak otomatis MIT.** Dibuat dengan ChatGPT menurut keterangan pemilik; lihat `docs/ASSET_ATTRIBUTION.md`                                           | `src/assets/brand/`, `build/icon.*`, `desktop/dekri-lab.ico`                   |
| Nama “DEKRi Lab”                                                                   | Tidak ada klaim merek terdaftar; lihat `docs/BRAND_CHECK.md`                                                                                          | —                                                                              |
| Font Inter                                                                         | SIL OFL 1.1                                                                                                                                           | `src/assets/fonts/`                                                            |
| Dependensi pihak ketiga dan Electron/Chromium                                      | Mengikuti lisensi masing-masing                                                                                                                       | `THIRD_PARTY_NOTICES.md`, SBOM                                                 |

Untuk saat ini, bagian yang bukan kode sumber **tidak** diberi lisensi terbuka eksplisit. Artinya, secara bawaan hak ciptanya tetap pada pemegang hak dan pihak lain tidak otomatis boleh menyalin ulang atau mendistribusikannya terpisah dari aplikasi. Pemilik dapat memilih lisensi konten (misalnya Creative Commons) bila menghendaki; itu keputusan pemilik dan belum dibuat.

Teks lisensi (`LICENSE`, `THIRD_PARTY_NOTICES.md`, OFL) disertakan dalam installer di folder `resources/licenses` (diuji pada paket Electron Linux; belum pada installer Windows).
